# A la recerca de l'Ohio de Barcelona

Quin barri i quina secció censal de Barcelona voten més com el conjunt de la ciutat?

**Llegeix l'informe:** <https://jordi-munoz.github.io/ohio_bcn/>

Anàlisi dels resultats de les eleccions municipals de Barcelona (1987–2023) a partir de les dades
del [Portal de Dades de Barcelona](https://portaldades.ajuntament.barcelona.cat/ca/microdades/78d2734c-35ee-49de-86c6-4bafef2e8e05)
i dels mapes de seccions censals de l'[INE](https://www.ine.es/dyngs/DAB/index.htm?cid=1389).

Aquest repositori només conté l'informe publicat (`index.html`).
